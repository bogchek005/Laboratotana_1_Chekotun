# ЛР №6 — огляд Git-файлів на секрети

## Команди

```powershell
git status --short
git ls-files
git grep -n -I -i -E 'password|passwd|secret|api.?key' -- .
git log --all --oneline -- tests/SecureLab.Api.Tests/lab-03-tests.http
```

## Класифікація знахідок

|Місце|Категорія|Рішення|
|-|-|-|
|`tests/SecureLab.Api.Tests/lab-03-tests.http:4`|**Буквальний справжній навчальний пароль**|Змінна середовища замість значення, рисунки 82–85|
|`infra/compose.yaml`|Відкриті локальні PostgreSQL credentials|Не використовувати поза локальним ізольованим стендом|
|`README.md`|Документування відкритих навчальних значень|Немає чинного приватного секрету в описі|
|`DbSeeder.cs`, `Lab03Identity.cs`, тести|Назви полів, методів і змінних|Переважно нормальний код, потребує контекстної оцінки|
|`unexpected-error.http`|Демонстраційний неправильний пароль|Не прирівнювати до чинного credential|

Кількість унікальних збігів у всьому робочому дереві не підтверджено окремим підрахунком; повторений термінальний вивід не можна механічно вважати числом унікальних секретів.

## Fix

```http
@password = {{$processEnv SeedUsers\\\\\\\_\\\\\\\_Password}}
```

Зміна у tracked файлі зафіксована на рисунку 83, commit — на рисунку 85.

## Залишковий ризик

Старі commits можуть зберігати колишнє значення. Рекомендована ротація навчального пароля і нерозголошення історичних значень. Повна історія Git, stash, інші клони й зовнішній CI не перевірялися.
